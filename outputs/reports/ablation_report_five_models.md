# Ablation Report (Five Models)

## Method

- Each tuned model was scored with all four features, then with each feature removed in turn.
- All versions used the same 50 repeated cross-validation folds on the training set only.
- F1 drop = F1 with all four features minus F1 without the feature. A bigger drop means the model relies more on that feature.
- Each drop was tested with the corrected resampled t-test, Holm-corrected across the four features within each model (alpha = 0.05).
- Model settings were not re-tuned for the reduced feature sets.
- The held-out test set was not used.
