# Leave-One-Scam-Type-Out Report (Extension)

## Purpose

Tests whether the five tuned models can detect a scam type they never saw during training, to show where the four structural features stop generalising. This experiment was added after the significance tests found no significant difference between the models (see the challenges and decisions log).

## Method

- **Unseen:** each model is trained on the training set without one scam type, then asked to classify that scam type. Recall = share flagged as scam.
- **Seen (control):** the same number of scam conversations is removed at random from all four types, so the scam type is still seen in training. Repeated 10 times and pooled. This keeps training size and class balance the same as the unseen case.
- **Generalisation gap** = seen recall minus unseen recall. A large gap means the model relied on having seen that scam type.
- Training split only; the held-out test set was not used. Tuned settings were not changed.

## Summary

- Hardest scam type to detect when unseen: **support** (average recall 0.535 across the five models).
- Largest average generalisation gap: **ssn** (+0.088).
- Smallest average generalisation gap: **refund** (-0.005).

## Limitation

Only recall on the held-out scam type is measured. False alarms on non-scam conversations are not measured here, because every non-scam conversation in the training split was used for training in this experiment.
